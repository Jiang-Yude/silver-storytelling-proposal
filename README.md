# 銀髮族 AI 說故事走進校園資源班計畫

一個讓阿公阿嬤、AI、孩子、學校四方都受益的社區共學方案。

**提案人**：江昱德、林學賢
**統籌**：永力扶輪社
**提案時間**：2026 春

## 線上閱讀

https://jiang-yude.github.io/silver-storytelling-proposal/

## 一句話

讓銀髮族走進資源班，每次半小時，由長輩說一段故事。
孩子被聽見、長輩有舞台、學校多一份外部資源、社區多一條代間共學的橋。

關於 AI：它不在現場、也不直接給孩子用。它是長輩的後台支援——幫忙把故事修順、生成繪本畫面、把場景投影出來。

## 內容大綱

- 為什麼做這件事（資源班的孩子、銀髮族的舞台、AI 的位置）
- 三個層次的設計（長輩培力 → 現場執行 → 成長追蹤）
- 預期效益（孩子、長輩、學校、社區四方共贏）
- 共享知識庫（會持續累加的永續性設計）
- 執行架構（角色分工）

無建置步驟，可直接以 `python3 -m http.server` 或 GitHub Pages 部署。
